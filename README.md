# Attribute Swap

Fabric клиентский мод для обмена атрибутов предметов с удобным GUI.

## Функции

✅ GUI через Mod Menu + Cloth Config  
✅ Выбор любого предмета → любой предмет  
✅ Отображение иконок предметов  
✅ Поддержка предметов из модов  
✅ Режим Toggle/Single  
✅ Назначение клавиш  
✅ Сохранение JSON-конфига  
✅ Поиск только в хотбаре  
✅ HUD-индикатор активных профилей  
✅ Неограниченное количество правил  

## Установка

1. Установите Fabric Loader
2. Скопируйте JAR в папку `%appdata%\.minecraft\mods`
3. Перезагрузите игру

## Управление

- **U** - Toggle Attribute Swap
- **I** - Открыть GUI конфигурации

## Конфигурация

Конфиг сохраняется в `config/attributeswap/config.json`

## Сборка

```bash
./gradlew build
```

JAR будет в `build/libs/`
